# /plan — Plan a feature implementation

Read CLAUDE.md for project context. Then use the planner agent to decompose the requested feature into implementable tasks with acceptance criteria.

Steps:
1. Read CLAUDE.md to understand the architecture and design system
2. Check existing code to understand current state
3. Break the feature into tasks (each < 2 hours)
4. Define acceptance criteria per task
5. Identify dependencies between tasks
6. Flag any risks or open questions

Output a structured plan in markdown.
